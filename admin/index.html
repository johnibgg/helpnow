Zone privilégiée (missions, portefeuille, commissions)

🔒 Réservé au backend sécurisé

Missions, portefeuille et commissions (10 %) sont protégés par RLS : non lisibles avec la clé publique. Ils passent par un endpoint serveur sécurisé — Edge Function admin-stats qui lit avec la clé service_role côté serveur (jamais dans cette page), gardée par un ADMIN_TOKEN. Le token est saisi localement (navigateur), jamais stocké dans le dépôt. Déploiement : voir backend/supabase/functions/admin-stats.
